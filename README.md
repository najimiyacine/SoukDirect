# SoukDirect — site de présentation

Site statique HTML/CSS, sans dépendance ni backend.

## Publication GitHub Pages
1. Créer un dépôt GitHub public (par exemple `soukdirect`).
2. Ajouter `index.html` à la racine du dépôt.
3. Dans Settings → Pages, choisir `Deploy from a branch`, branche `main`, dossier `/root`.
4. Enregistrer. GitHub Pages publiera le site après le déploiement.

## Personnalisations avant publication
- Ajouter le nom et les coordonnées du porteur de projet.
- Remplacer les hypothèses illustratives par les données du terrain.
- Ajouter des photos authentiques avec droits d'utilisation.
- Ajouter une adresse e-mail professionnelle et une politique de confidentialité si un formulaire de collecte est ajouté.

Le site décrit un concept en validation. Il ne comporte ni réservation réelle, ni paiement, ni suivi GPS opérationnel.
